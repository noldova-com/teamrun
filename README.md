# TeamRun

TeamRun is a desktop workspace designed to bring your coding agents, project conversations and file changes together. Choose who helps with a task, follow the work and review the results in one place.

## Work with your agents

Whether you use one coding agent or several, TeamRun is built around a straightforward workflow:

1. **Bring a project.** Keep conversations connected to the local folder you're working on.
2. **Choose who helps.** Select a provider and account, or create named teammates with their own roles and model preferences.
3. **Work in conversation.** Describe a task, share files or images, and follow replies and project changes.
4. **Review and continue.** Respond to permission requests, inspect the results and return to the conversation when you need it.

Named teammates let you choose who participates in a conversation. Automatic delegation between agents and working with agents on remote computers are separate future capabilities.

## Platforms

TeamRun targets Windows, macOS and Linux on x64 and ARM64.
