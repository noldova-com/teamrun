# Changelog

**Scope:** What each released version of TeamRun holds, newest first.

Each version's section is written by the pull request that changes the version, from the pull requests merged since the previous version; other pull requests don't edit this file.

## 0.0.1

- The first version of `@noldova/teamrun` and the packages it depends on, `@noldova/teamrun.cli`, `.core`, `.protocol`, `.providers`, `.runtime`, `.services` and `.window`, under the MIT License, all at the same version.
- TeamRun's app, built on these packages: chats with AI agents from several providers, teammates with roles, and approvals of their work in one place.
