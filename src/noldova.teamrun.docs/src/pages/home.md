# TeamRun

TeamRun is a desktop app for working with AI agents as a team.
You chat with agents from several AI providers, give them teammates' roles, and follow and approve their work in one place.

TeamRun runs on macOS, Windows and Linux, and is free under the MIT licence.

## Start here

- [Getting started](getting-started.md): from install to a first answer from a teammate.
- [Install](install.md): the download for your system, and how updates work.
- [Providers and sign-in](providers.md): adding Claude Code, Codex, GitHub Copilot and the other providers, and signing in to each on your own account.
- [What each provider can do](provider-features.md): which features each provider has in TeamRun.
